# Security Policy

TuberBot Market is a product preview. Live payments, payouts, seller verification, and public safe-payment claims are disabled by default.

Please do not post credentials, personal data, payment details, or exploit instructions in a public issue. Use GitHub's private vulnerability reporting for this repository when it is available. If that channel is unavailable, open a public issue containing only a non-sensitive request for a private contact channel.

Reports should identify the affected route or component, the security impact, and a minimal reproduction that contains no real user or financial data.
