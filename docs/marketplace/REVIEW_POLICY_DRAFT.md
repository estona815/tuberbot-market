# Review policy draft

> **DRAFT_NEEDS_COUNSEL — 법률 검토 전 운영 정책으로 게시하지 마십시오.**

## 자격과 공개

- `COMPLETED` 주문의 실제 양 당사자만 주문당 역할별 후기 1개를 작성한다.
- 양측 작성 완료 또는 첫 작성 후 14일에 동시 공개한다. 공개 전 상대방에게 내용이 노출되지 않는다.
- development seed, 취소/환불만 된 주문, 운영자 생성 후기는 공개 지표에 포함하지 않는다.
- 평점·완료율은 TuberBot 내부 거래만 사용하고 표본 수와 기간을 함께 표시한다.

광고주는 일정·소통·품질·brief 반영·재거래 의향을, creator는 brief 명확성·응답·합리적 수정·계약 준수·재거래 의향을 평가한다.

## 제한/삭제 사유 초안

개인정보·계좌·연락처 노출, 협박/차별/혐오, 스팸, 무관 내용, 사칭/조작 증거, 법원·기관 명령, 실제 거래와 무관한 후기만 제한한다. 단순히 부정적이거나 운영자와 의견이 다르다는 이유로 숨기지 않는다.

## 절차

신고 → 자동 공개 유지 또는 긴급 임시 제한(reason 필요) → Moderator 검토 → 작성자 통지 → 유지/일부 마스킹/제한/삭제 → 14일 이의제기 → 다른 검토자 결정 → 복구 가능. 원문·모든 revision·결정은 접근 제한된 append-only audit로 보존한다.

2026-07-21 시행 전자상거래법 개정은 사용후기 삭제 기준과 삭제 시 이의제기 절차를 사전 공개하는 규율을 포함하므로, 공개 전 법률가가 정확한 적용 범위와 화면 문구를 검토한다: [개정 이유 및 법령](https://law.go.kr/lsInfoP.do?ancYnChk=0&chrClsCd=010202&efYd=20260721&lsId=&lsiSeq=282793&urlMode=lsEfInfoR&viewCls=lsRvsDocInfoR).

## 운영 지표

신고율, 처리시간, 유지/제한/복구율, 이의제기 인용률을 role/category별로 관찰하되 민감 특성을 추론하지 않는다. 관리자 개입 후 평균 평점을 성과 목표로 두지 않는다.
